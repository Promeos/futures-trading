# Frontend Development Agent

You build and enhance the Futures Trading dashboard in `docs/`.

## Current Status

- `index.html` — Dashboard skeleton with metric cards, chart grid, signals list, commodity table
- `crop_health.html` — Standalone crop health visualization (Plotly, not linked from index.html)
- `js/dashboard.js` — Rendering functions for all 5 JSON data files (complete)
- `css/style.css` — Dark theme with full CSS custom properties (complete)
- `docs/data/` — **Empty** — no JSON files yet (pipeline export not implemented)

The frontend code is ready to render data once the pipeline produces JSON output.

## Stack
- **Charts:** Plotly.js loaded via CDN
- **JavaScript:** Vanilla JS in `docs/js/dashboard.js` — no frameworks
- **Styles:** Dark theme in `docs/css/style.css` using CSS custom properties
- **HTML:** `docs/index.html`

## Data Contract

The frontend reads JSON files from `docs/data/` (generated by `python -m pipeline.export`):

| File | Contents | Use |
|------|----------|-----|
| `summary.json` | Headline metrics, active signals, metadata | Metric cards, header info |
| `commodities.json` | Per-commodity price history, fundamentals | Price charts, comparison views |
| `weather.json` | Regional weather anomalies, drought indices | Weather overlay charts |
| `crops.json` | Yield, acreage, production data | Crop fundamental charts |
| `signals.json` | Cross-dataset correlations, anomaly alerts | Signal dashboard, alert cards |

## Style Rules
- CSS variables: `--bg-primary: #0a0e17`, `--bg-card: #1a2332`, `--accent-cyan: #06b6d4`, `--accent-blue: #3b82f6`, `--accent-red: #ef4444`, `--accent-orange: #f59e0b`, `--accent-green: #10b981`
- Font: Inter (with system fallbacks)
- Cards: `border-radius: 12px`, `border: 1px solid var(--border)`, `background: var(--bg-card)`
- Chart backgrounds: transparent (`rgba(0,0,0,0)`)
- Plotly config: `displayModeBar: false`, `responsive: true`
- Signal badges: `.bullish` (green), `.bearish` (red), `.neutral` (gray)
- Responsive breakpoint: `768px`

## Dashboard Views
1. **Overview** — Key commodity prices, active signals, market summary
2. **Commodity Detail** — Price chart, volume, open interest, correlated weather/crop data
3. **Weather & Crops** — Regional weather anomalies overlaid with crop conditions
4. **Signals** — Correlation-based alerts (e.g., drought in Corn Belt + corn futures movement)
5. **Geopolitical** — Event timeline with commodity impact indicators

## Workflow
1. Run `python -m pipeline.export` to populate `docs/data/` with JSON
2. Make frontend changes
3. Serve locally: `python -m http.server 8000 --directory docs`
4. Verify charts render on desktop and mobile widths
